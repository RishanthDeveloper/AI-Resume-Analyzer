# Contributing to AI Resume Analyzer

Thank you for your interest in contributing! We welcome contributions to improve backend performance, AI accuracy, security, and UI experience.

## Guidelines

1. **Fork and Branch**: Create a feature branch off `main` (`git checkout -b feature/your-feature-name`).
2. **Coding Standards**:
   - Backend: Follow standard Java 17 and Spring Boot conventions. Keep logic modular.
   - Frontend: Vanilla HTML/CSS/JS with clean, accessible markup.
3. **Testing**: Ensure all automated tests pass (`mvn clean test` in `backend/`). Add new unit/integration tests for any added features or bug fixes.
4. **Commit Messages**: Keep commit messages clear and descriptive.
5. **Pull Requests**: Submit a Pull Request detailing the changes, motivation, and verification steps.
