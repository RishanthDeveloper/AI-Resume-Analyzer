# Security Policy

## Reporting Security Vulnerabilities

We take security seriously. If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

- **Email**: Send vulnerability reports to `security@rishanthdeveloper.com` (or create a private GitHub Security Advisory).
- **Include**:
  - Description of the vulnerability and potential impact.
  - Step-by-step proof of concept or reproduction steps.

We will acknowledge your report within 48 hours and provide updates on resolution status.
